📅 Отчет за 08.03.2026

- Вложенный тернарный оператор: Можно писать А if условие1 else B if условие2 else C. Это как сложная система скидок: "Если VIP — 20%, если постоянный — 10%, иначе — 0%".

- Краткость vs Читаемость: Однострочники хороши, когда логика простая. Но твой первый вариант с split был надежнее, так как он сработает, если счет будет, например, 10:2 (индекс g[2] в этом случае укажет на «0», а не на «2»).

- Отрицание как действие: В Python -n — это короткая запись для n * -1.

- Генератор списка: Мы создаем новый список на лету. Оригинальный список lst при этом не меняется (это важно для сохранности данных).

- Технический совет: f-строки
Чтобы склеить число и текст красиво, используй f-строки. Это самый современный и удобный способ в Python.
Пример: f"{number}: {text}"

- f-строки (f"{var}"): Самый быстрый и читаемый способ склеивать текст и переменные. Python сам превратит число внутри {} в текст.

- Итерация: Переменная line в цикле for line in lines — это каждый раз новая строка из твоего списка.

- Словари (dict): Идеальны для задач типа «замени это на то». Это быстрее и чище, чем 10 веток if.

- Метод .join(): Список ['T', 'A', 'A'] превращается в "TAA". Это стандарт объединения строк.

- Масштабируемость: Если завтра в ДНК добавят еще 10 новых букв, в словаре ты просто добавишь 10 строчек, а в if/else ты запутаешься в отступах.

- Ошибка KeyError: Возникает, когда ты пытаешься вытащить из словаря значение по ключу, которого там не существует.

- Безопасный доступ: Метод .get(ключ, значение_по_умолчанию) — твой главный защитник от падения программы при работе со словарями.

- Фильтрация в генераторе: Конструкция [x for x in list if условие] позволяет не только обрабатывать данные, но и сразу отсеивать «мусор».

- input() в тестах: Использование input() в автоматических тестах приводит к ошибке EOFError. Функции должны получать данные только через параметры.

- Точность строк: Автоматические тесты сверяют каждый символ. Лишний пробел или кавычка ' внутри строки сделают решение «неверным».

- f-строки и кавычки: Если тебе нужно вернуть строку, просто пиши f"Текст {переменная}". Не нужно оборачивать её в дополнительные слои кавычек, если этого не требует условие.

- Распаковка/Упаковка (*args): Позволяет функции принимать неограниченное количество аргументов. По стандарту принято писать *args (от англ. arguments), но *a технически работает так же.

- Гибкость: Такой код более «живучий». Ему всё равно, передашь ты 3 числа или 100 — он сработает без ошибок.

- Кортеж (Tuple): Под капотом *a создает неизменяемый список (кортеж). Именно поэтому к нему можно применить функцию sum().

- Сравнение строк: Чтобы проверить, какой оператор пришел, мы сравниваем переменную со строкой: if operator == '+':.

- Взаимоисключающие условия: Поскольку оператор может быть только одним (либо плюс, либо минус), лучше всего использовать цепочку if -> elif -> elif. Как только Python найдет верное условие, он не будет тратить время на проверку остальных.

- Проблема None: Если функция возвращает None, значит код «пролетел» мимо всех твоих return. Проверь условия if — скорее всего, они не выполнились.

- Обращение к словарю: Синтаксис dictionary[key] — это мгновенный доступ к данным.

- eval(string): Функция, которая исполняет строку как программный код.

- Безопасность: Никогда не используй eval с данными, которые вводит человек (как input), чтобы избежать «инъекций» вредоносного кода.

- Приведение типов: Перед тем как скармливать данные в eval через склеивание, их нужно превратить в str

- Тернарный оператор: Способ сократить if/else до одной строки: [Результат_если_Истина] if [Условие] else [Результат_если_Ложь].

- Метод .join(): Используется для склейки списка строк в одну строку. Пример: "".join(['A', 'B', 'C']) превратится в "ABC".

- while vs for: for используем, когда знаем количество шагов. while — когда идем до достижения конкретного условия (состояния).

- Функция enumerate(list, start=0): Позволяет в цикле получать одновременно и индекс (номер), и значение элемента.

- Функция range(start, stop): Генерирует последовательность чисел. Важно помнить, что stop не включается в диапазон, поэтому для включения последнего числа используем stop + 1.

- O(1) — Скорость поиска: В словаре поиск по ключу происходит мгновенно, независимо от размера словаря. Это критично для высоконагруженных систем.

- Функции как значения: В словаре можно хранить не только строки или числа, но и целые функции. Это позволяет создавать гибкую архитектуру (паттерн «Стратегия»).

- JSON и Словари: Почти все данные в интернете (API) передаются в формате JSON, который в Python один в один превращается в словарь. Уметь работать со словарями — значит уметь работать с интернетом.
