1. **Python**

- .count() — Метод списка. Пробегает по всему списку один раз и возвращает количество указанных элементов. Очень удобно, когда не нужно менять данные, а нужно их только посчитать.

- Цепное условие — В return можно записывать сложные логические выражения с and. Функция сама вычислит их и вернет итоговый True или False.

- len(walk) == 10 — Базовая проверка на время.

- Баланс векторов — Для возврата в 0 сумма противоположных векторов должна быть равна.

- Итоговая проверка — Сравнение результатов (x == 0, n == s и т.д.) должно происходить после того, как все данные собраны, а не в процессе их сбора.

- Размещение return — если ты возвращаешь True внутри цикла, функция прервется на первом же шаге. Проверку финиша всегда делай вне цикла.

- Булева арифметика: True в математических операциях ведет себя как 1, а False — как 0.

- Приоритет операций: Сначала считаются выражения в скобках (сравнения), потом умножение, потом вычитание.

- Прямой возврат условия: Вместо того чтобы городить if/else, можно просто написать return и само условие.

- Избегай == True: В условиях if или return достаточно просто написать имя переменной: if employed: вместо if employed == True:.

 - Граница range в Python: Функция range(start, stop) никогда не включает число stop. Чтобы цикл дошел до индекса N, нужно писать range(..., N + 1).

 - Формула «Скользящего окна»: Чтобы перебирать группы по k элементов в списке длиной n и не вылететь за границу, цикл всегда ограничивается: range(n - k + 1).

- Обновление рекорда: Если задача — найти «самое длинное/лучшее», проверка if current > best должна находиться внутри цикла. Если вынести её за цикл, программа сравнит с рекордом только последний элемент.

- Метод .join(): Это самый быстрый способ склеить список строк в одну. Синтаксис: "разделитель".join(список). Для склейки без пробелов — "".join(...).

- Срезы (Slices): list[start:stop] копирует часть списка. Элемент stop не включается. Чтобы взять k элементов, начиная с индекса i, пишем list[i : i + k]

- Интерпретатор vs Компилятор: Python — интерпретатор. Он «переводит» и выполняет код построчно в реальном времени. Это позволяет быстро тестировать куски кода, но делает его медленнее языков-компиляторов (как C++).
