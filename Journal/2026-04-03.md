1. Структура данных 
    2 типа:
- линейные  (В линейных структурах данных элементы располагаются последовательно, один за другим. Поскольку элементы расположены в определенном порядке, их легко реализовать.)
- нелинейные 

Линейные:

- Array он же массив, он же список
- Stack LIFO (англ. last in, first out — «последним пришёл — первым ушёл»)
- Queue FIFO (от англ. First In, First Out — «первым пришёл, первым ушёл»)
- Linked List В структуре данных «связанный список» элементы данных соединены между собой через ряд узлов. Каждый узел содержит элементы данных и адрес следующего узла.

Нелинейные:
- Graph Data Structure (В графовой структуре данных каждый узел называется вершиной, и каждая вершина соединена с другими вершинами ребрами.)
- Trees Data Structure  (В древовидной структуре данных между двумя вершинами может быть только одно ребро.)


Программирование — это работа со структурами данных и алгоритмами. Структуры данных используются для хранения информации, а алгоритмы — для решения задач с использованием этих данных.

- Big-O notation (худший вариант)
- Omega notation (лучший вариант)
- Theta notation (средний вариант)

- среднее время работь 0(n*log(n)) , 0 (log n)
- худшее время работы 0 (n квадрат)  0 (n)


types of Queue:

- Simple Queue
В простой очереди добавление происходит в конец, а удаление — в начало. Она строго следует принципу FIFO (первым пришёл — первым обслужен).

- Circular Queue
В кольцевой очереди последний элемент указывает на первый, образуя циклическую связь.

- Priority Queue
Приоритетная очередь — это особый тип очереди, в которой каждому элементу присваивается приоритет, и элементы обслуживаются в соответствии с этим приоритетом. 

- Deque (Double Ended Queue)
В двусторонней очереди элементы можно добавлять и удалять как с начала, так и с конца
