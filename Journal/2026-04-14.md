## ✅ Что посмотрел на ютубе: Базы данных и SQL
1. **Разница подходов (SQL vs NoSQL):**
   - **SQL (Реляционные):** Строгая структура (таблицы, колонки). Идеально для связанных данных (пользователи, заказы). Примеры: PostgreSQL, MySQL.
   - **NoSQL (Нереляционные):** Хранят данные как документы (JSON) или ключ-значение. Гибкие, но без строгих связей. Примеры: MongoDB, Redis.
2. **Нормальные формы (Правила чистоты БД):**
   - *1-я форма:* В одной ячейке — только одно значение (нельзя писать "Математика, Физика" в одну ячейку).
   - *2-я форма:* У каждой записи должен быть уникальный идентификатор — **Primary Key (Первичный ключ / ID)**.
3. **Связи между таблицами:**
   - **One-to-Many (Один-ко-Многим):** Самая частая. (Один учитель — много предметов). Реализуется через **Foreign Key (Внешний ключ)**.
   - **One-to-One (Один-к-Одному):** (Один человек — один паспорт).
   - **Many-to-Many (Много-ко-Многим):** (Студенты и Учителя). Требует создания третьей (промежуточной) таблицы.
4. **Основы синтаксиса MySQL:**
   - *CRUD:* `INSERT INTO` (создать), `SELECT` (прочитать), `UPDATE` (обновить), `DELETE` (удалить).
   - *Агрегация:* `COUNT`, `SUM`, `AVG`, `MAX`, `MIN` + группировка `GROUP BY`.
   - *Объединение (JOIN):* 
     - `INNER JOIN` (только совпадения в обеих таблицах).
     - `LEFT/RIGHT JOIN` (всё из одной + совпадения из другой).
     - `FULL JOIN` (всё из обеих).

## ✅ Что посмотрел на ютубе: Уровни языков программирования
1. **Низкоуровневые (Ассемблер, C):**
   - Близки к "железу". Управляют памятью напрямую.
   - *Плюсы:* Максимальная скорость и производительность.
   - *Минусы:* Очень сложны в написании, код привязан к конкретному процессору.
2. **Высокоуровневые (Python, Java, JS):**
   - Близки к человеческому языку.
   - *Плюсы:* Быстрая разработка, безопасность (не сломаешь память), кроссплатформенность.
   - *Минусы:* Медленнее работают из-за дополнительных "прослоек" (интерпретаторов).
3. **Как они работают:**
   - *Компилятор (C, Java):* Переводит весь код в машинный (нули и единицы) *до* запуска.
   - *Интерпретатор (Python):* Читает и выполняет код строчка за строчкой "на лету".
4. **Синергия (AHA! момент):** Разработчики используют высокоуровневые языки для быстрой разработки, а самые тяжелые куски программы пишут на низкоуровневых языках (как Pandas в Python написан на C).
