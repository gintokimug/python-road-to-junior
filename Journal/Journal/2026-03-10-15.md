- Позиционные аргументы: Передаются строго по порядку ("Иван", "Директор").

- Именованные аргументы: Передаются с указанием имени (access_level=10), что позволяет менять их порядок или пропускать необязательные.

1. Анатомия функций и Аргументы
- Обязательные vs Дефолтные: Обязательные аргументы всегда стоят слева, те, что со значениями по умолчанию (role="Продавец") — справа.

- Именованные вызовы: Можно «перепрыгивать» через аргументы, называя их явно: func(name="Иван", access=5).

Упаковка/Распаковка (*args):

- Звездочка в def — это «молния», которая застегивает все лишние аргументы в один кортеж (tuple).

- Звездочка при вызове — это «рассыпание» списка по отдельным ячейкам функции.

2. Типы данных и их «Валютный обмен»
- Число - строка: Чтобы работать с цифрами внутри числа (например, возвести каждую в квадрат), нужно превратить int в str.
 Итерировать (проходиться циклом) по числу напрямую нельзя.

 - Конкатенация: Помни, что 1 + 1 = 2 (математика), а "1" + "1" = "11" (склейка). Для формирования сложных строк-ответов часто приходится возвращать числа обратно в тип str.

 - f-строки и форматирование: Универсальный инструмент f"{value:.2f}" одновременно округляет число до 2 знаков и превращает его в строку.

 3. Списки и Сортировка (Фундамент)
 - list.append() vs list += ...: Для добавления одного элемента в список всегда используй .append().

 - .sort() vs sorted():sort() — меняет оригинал «на месте» (на выходе дает None).sorted() — создает новую отсортированную копию, оригинал не трогает.

 - Метод .pop(): Забирать элемент с конца списка (.pop()) — это мгновенная операция (O(1)). Забирать из начала или середины — долго (O(n)), так как Python сдвигает все остальные элементы.

 4. Циклы и Итерация
- for x in list: Мы берем сами значения. Подойдет для чтения или поиска.

- for i in range(len(list)): Мы работаем с индексами (адресами). Это единственный способ изменить элемент внутри оригинального списка прямо в процессе цикла.

- List Comprehension (Магия в одну строку): Конструкция [результат for элемент in источник if условие]. Позволяет заменять громоздкие циклы элегантными однострочниками.
