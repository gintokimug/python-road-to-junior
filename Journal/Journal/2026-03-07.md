    1. Логика и Потоки (Loops & Returns)
Правило return: return внутри цикла завершает всю функцию на первой же итерации. return под циклом (с тем же отступом, что и for) ждет, пока цикл доделает всю работу.

Бесконечный while: Всегда проверяй, изменяется ли переменная условия внутри цикла (например, year += 1). Если она не растет, программа «зациклится» навсегда.

Двойная работа: Используй if / elif, если условия взаимоисключающие. Это быстрее, чем два отдельных if, так как Python пропустит вторую проверку, если сработала первая.

2. Типы данных (Data Types)
Числа в кавычках: '7' — это не число, а картинка символа. Математика с ней не работает. Всегда делай int(), если планируешь складывать или сравнивать как числа.

Суммирование: Функция sum() ломается на списке, где есть хотя бы одна строка. Сначала преврати всё в int через цикл или генератор.

Ловушка строк: Сравнение строк '10' > '2' выдаст False, потому что Python сравнивает первые символы (1 меньше 2). Для правильного счета всегда переводи в int.

3. Инструменты строк (String Tools)
split vs strip: split(':') — это нож, он режет строку на части и делает список. strip(':') — это наждачка, она только стирает символы по самым краям строки.

Индексы: В строке "3:2" индекс [0] — это 3, а индекс [1] — это двоеточие. Не пытайся делать int(point[1]).

4. Функции и коммуникация
print vs return: print — это записка для тебя (человека). return — это передача документа следующему отделу (программе). Без return результат функции будет None.

Глобальное vs Локальное: Если ты изменил переменную p = 5000 внизу кода, но в print(nb_year(..., 1200)) оставил старое число — функция возьмет то, что ты передал ей «в руки» (1200).

*List Comprehension (Генератор списка):*
Твой финальный вариант [что_делаем for элемент in список] — это самый мощный инструмент Python. Он заменяет сразу три строки: создание пустого списка, цикл for и метод .append().

В программировании 2% — это не число 2, а множитель 0.02.

Практика: Всегда дели входящий percent на 100 внутри формулы, чтобы не зависеть от того, как пользователь ввел данные.

*Принудительное округление (int):*
В задаче было условие «нет дробных людей».

Важно: int() в Python не просто убирает точки, он отбрасывает дробную часть (округляет вниз). Это идеальный инструмент для задач, где нужно считать «целые единицы» (людей, бутылки, коробки).

*Принудительное приведение типов:*

В sum_mix мы использовали генератор (int(x) for x in arr). Это «фильтр», который берет каждый предмет, превращает его в число и только потом отдает на склад (sum).

Запомни: Если на входе «грязные» данные (смесь строк и чисел), сначала прогони их через int() или str().

*Скобки и приоритеты:*

В int(time * 0.5) сначала выполняется умножение, потом округление.

В sum(int(x) for x in arr) сначала каждый элемент становится числом, потом работает сумма.

Запомни: Всегда проверяй, на что именно надеты скобки твоей функции.
