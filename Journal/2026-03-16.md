1. **Python**

- Unicode: Стандарт, который связывает числа и символы.
- Синтаксис: chr(число) - строка (символ).
- Связка: Почти всегда chr() работает в паре с ord(). Если видишь одно, значит, где-то рядом может понадобиться второе.
- Вложенный цикл (Nested Loop): Внешний цикл перебирает «контейнеры» (слова), внутренний — содержимое этих контейнеров (буквы).
- Сброс аккумулятора: Переменные для промежуточных сумм должны создаваться внутри внешнего цикла.
- Scope (Область видимости): Переменная цикла (letter) доступна только внутри этого цикла или после его завершения, но не до начала.

- Accumulator Pattern: Использование переменной (current_score) для накопления суммы в итерациях.

- *Nested Logic: Внешний цикл отвечает за выборку объектов, внутренний — за их анализ.*

- .isdigit() — Метод строки. Возвращает True, если в строке только цифры. Если есть хоть один пробел или буква — False.

- max(list, key=...) — Ищет лидера. Через key можно задать правило (например, искать слово не по алфавиту, а по сумме очков).

2. **Developer**

- Валидация: Процесс проверки входных данных перед их обработкой (в этой задаче мы её опустили по условию).
- Парсинг: Преобразование данных из одного формата в другой (обычно из менее структурированного в более структурированный).
