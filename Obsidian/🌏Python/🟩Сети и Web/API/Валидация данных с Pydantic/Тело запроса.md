 # Шаг 1: Метод POST и отличия от GET

До этого момента мы пользовались только методом **GET**.  
Мы говорили серверу: "Дай мне список задач" или "Дай мне задачу номер 5".

Но если мы хотим **отправить** данные на сервер (создать задачу, зарегистрироваться, загрузить файл), метод GET нам не подходит. Для этого существует метод **POST**.

### Аналогия: Открытка vs Конверт

Представьте, что HTTP-запрос — это почтовое отправление.

1. **GET — это Открытка.**
    
    - Всё, что вы хотите передать, написано прямо на ней (в URL).
        
    - Почтальон, соседи и любой, кто возьмет её в руки, видит текст (?password=123).
        
    - Места на открытке мало (у URL есть ограничение по длине, обычно около 2000 символов).
        
2. **POST — это Письмо в запечатанном конверте.**
    
    - На конверте написан только адрес (URL).
        
    - Сами данные лежат **внутри** (в Теле запроса / Body).
        
    - Никто не видит содержимое, пока не вскроет конверт.
        
    - Внутрь можно положить хоть один листок, хоть толстую книгу "Война и мир" (ограничений по объему практически нет).
        

### Технические отличия

|   |   |   |
|---|---|---|
|Характеристика|GET (Чтение)|POST (Создание)|
|**Где данные?**|В строке адреса (URL)|Внутри запроса (**Body**)|
|**Безопасность**|**Низкая.** Данные сохраняются в истории браузера.|**Выше.** Данные не видны в строке адреса.|
|**Объем данных**|Маленький (только короткий текст)|Огромный (текст, файлы, картинки)|
|**Кэширование**|Браузер может сохранить результат|Браузер никогда не кэширует|
|**Смысл**|Не меняет состояние сервера (только чтение)|**Меняет состояние** (создает новые записи)|

### Как выглядит POST-запрос?

Если "просветить" POST-запрос рентгеном, он выглядит так:

```python
POST /tasks HTTP/1.1
Host: my-api.com
Content-Type: application/json

{
  "name": "Выучить FastAPI",
  "priority": 10
}
```

Обратите внимание на пустую строку после заголовков. Всё, что ниже неё — это **Тело запроса (Request Body)**. Именно здесь мы будем передавать наши Pydantic-схемы.

### Когда что использовать?

Запомните простое правило:

- Хотите **получить** информацию? Используйте **GET**.
    
- Хотите **создать** что-то новое или отправить секретные данные? Используйте **POST**.
