>[!abstract] Теория
Параллельный (одновременный) перебор нескольких коллекций.
>**Что делает:** Берет несколько списков (или других коллекций) и сшивает их попарно, как зубчики застежки-молнии. Возвращает кортежи `(элемент_из_1, элемент_из_2)`. **Архитектура (Ленивые вычисления):** `zip` не создает новый список в памяти! Он создает ленивый генератор. Чтобы увидеть результат, нужно обернуть его в `list()` или `dict()`.
>> [!Note] Пример 1
>>```python
 >># Пример 1: Перебор нескольких списков одновременно 
 >>zip берет по одному элементу из каждого списка и собирает их в кортеж. 
 >>for name, salary in zip(names, salaries):
 >> print(f"Сотрудник {name} получает {salary}")
>>   # Пример 2: Быстрое создание словаря 
>>   # Ключи и значения сшиваются попарно. 
>>   keys = ['id', 'username', 'role'] 
>>   values = [42, 'admin_01', 'superuser'] 
>>   user_dict = dict(zip(keys, values)) 
>>   print(user_dict) # {'id': 42, 'username': 'admin_01', 'role': 'superuser'} 
>>    # Пример 3: Работа со списками разной длины 
>>    # zip останавливается, когда заканчивается самый короткий список. Остаток отбрасывается. 
 >>   list_a = [1, 2, 3, 4, 5]
>>     list_b = ['a', 'b'] 
>>     print(list(zip(list_a, list_b))) # [(1, 'a'), (2, 'b')]
>
>> [!Note] Пример 2
>>```python
>># 2. ZIP: Сериализация сырых данных из БД  
>># Базовые драйверы баз данных (типа sqlite3 или psycopg2) часто возвращают 
>># результат SELECT-запроса как список кортежей (без названий колонок). 
>># А фронтенд (мобильное приложение) ждет от нас красивый JSON (словари). 
>># То, что мы знаем о структуре таблицы 
>>columns = ["user_id", "email", "is_active", "balance"] 
>>
>># То, что прилетело из голой базы данных 
>>db_rows = [ 
>>(101, "admin@mail.com", True, 5000.50), 
>>(102, "bot@mail.com", False, 0.0), 
>>(103, "sergey@mail.com", True, 150.00) 
>>] 
>>
>># Превращаем сырые кортежи в список словарей для отправки на фронтенд 
>>json_response = []
>> for row in db_rows: 
>> # zip склеивает названия колонок с реальными значениями
 >> 
 >>user_dict = dict(zip(columns, row)) json_response.append(user_dict) 
 >>
>> # Теперь это валидный формат для отправки по API 
>> print(json_response[0]) 
>> # {'user_id': 101, 'email': 'admin@mail.com', 'is_active': True, 'balance': 5000.5}
