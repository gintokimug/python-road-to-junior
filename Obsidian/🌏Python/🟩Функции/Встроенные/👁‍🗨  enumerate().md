>[!abstract] Теория
>Берет любую коллекцию (список, кортеж, строку) и «приклеивает» к каждому элементу его порядковый номер (индекс). На каждом шаге выдает кортеж: `(индекс, значение)`.
>enumerate(iterable, start=0)
>- **iterable** — итерируемый объект, элементы которого нужно проиндексировать. Это может быть список, кортеж, строка, множество, словарь и другие объекты, поддерживающие итерацию.
>- **start** (необязательный) — начальное значение индекса. По умолчанию — 0.
>
>> [!Note] Пример использования (цикл **for**)
>> ```python
>>fruits = ["apple", "banana", "cherry"]
>for index, fruit in enumerate(fruits):
 >   print(index, fruit)
>0 apple
>1 banana
>2 cherry
>
>> [!Note] Пример испозования (значения **индекса**) 
>>```python
>>letters = ['a', 'b', 'c']
>>for index, letter in enumerate(letters, start=1):
>>    print(index, letter)
>>1 a
>>2 b
>>3 c
>
>
>> [!Note] Пример использования (преобразование в список)
>>```python
>>numbers = [10, 20, 30]
>>print(list(enumerate(numbers)))  # [(0, 10), (1, 20), (2, 30)]
```
