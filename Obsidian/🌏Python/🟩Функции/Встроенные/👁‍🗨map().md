>[!abstract] Теория
**Назначение:** Применить одну и ту же функцию к каждому элементу коллекции.
**`map()`** — это встроенная функция в Python, которая позволяет применить определенную функцию к каждому элементу итерируемого объекта (например, списка, кортежа или строки) без использования явных циклов `for`.
>
map(функция, итерируемый_объект)
>
>
>- **Функция:** правило, по которому нужно изменить каждый элемент (это может быть обычная функция через `def` или анонимная `lambda`).
>    
>- **Итерируемый объект:** список, кортеж, строка и т.д., элементы которого мы хотим обработать.
>
>
>```python
># Пример 1: Конвертация типов данных 
># Функция int применяется к каждой строке в списке. 
># Так как map ленивый, оборачиваем результат в list(), чтобы выполнить код. 
>str_numbers = ['10', '20', '30'] 
>int_numbers = list(map(int, str_numbers)) 
>print(int_numbers) # [10, 20, 30]
>```
>
>Извлечение данных из JSON (API ответы)
>```python
># Имитируем выгрузку из кассовой системы или базы данных магазина
>transactions = [
>    {"receipt_id": 1045, "cashier": "Иванов", "total": 1250.50},
>   {"receipt_id": 1046, "cashier": "Смирнова", "total": 890.00},
>    {"receipt_id": 1047, "cashier": "Иванов", "total": 3400.99}
>]
>
># Задача: вытащить только номера чеков для передачи в другую систему
>receipt_ids = list(map(lambda t: t["receipt_id"], transactions))
>
>print(receipt_ids) 
># Вывод: [1045, 1046, 1047]
>```

>```python
># 3. MAP: Очистка грязных данных на уровне C 
># Пользователи или кривые парсеры часто присылают данные с лишними пробелами 
># или в виде строк вместо чисел. 
># Ситуация: пришел список ID пользователей из веб-формы (всё в строках с пробелами)
>raw_ids_from_frontend = [" 105 ", "204", " 310 ", "400"] 
>
># Если использовать List Comprehension, Питон будет вызывать метод .strip() на уровне байт-кода
 ># Если использовать map, мы передадим C-метод str.strip напрямую. Это микро-оптимизация. 
 ># 1. Быстро очищаем от пробелов (передаем ссылку на метод класса str) 
 >cleaned_strings = map(str.strip, raw_ids_from_frontend) 
 >
 ># 2. Быстро конвертируем в int 
 >valid_ids = list(map(int, cleaned_strings)) print(valid_ids) # [105, 204, 310, 400]
