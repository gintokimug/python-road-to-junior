
> [!abstract] Теория
> `sum()` — это встроенная функция, которая суммирует элементы **итерируемого объекта** (того, что можно перебрать).
> 
> - **К чему применять:** К спискам (`list`), кортежам (`tuple`) и множествам (`set`), если внутри лежат числа (`int` или `float`).
> - **Логика:** `sum()` принимает **один** аргумент (список/коллекцию). Нельзя написать `sum(1, 2, 3)`, нужно писать `sum([1, 2, 3])`. Помни об этом, когда будешь считать общую стоимость товаров в своих будущих скриптах.
>   
>> [!Пример]
>> ```python
>> prices = [100, 250, 50]
>>total = sum(prices) # Передаем переменную-список
>>print(total) # Выведет 400
>> ```
>>
>
>>[!warning] Внимание
>> Нельзя складывать строки через `sum()`. Для склеивания строк мы используем метод `.join()`
