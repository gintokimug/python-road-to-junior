> - **Логика:** Напрямую из `int` в `list` попасть нельзя. 
>     
> - **Схема:** `int` ➡️ `str` ➡️ `list`.
> - Синтаксис:** `list(str(123))` даст тебе `['1', '2', '3']`. Помни: цифры внутри станут **строками**. Если нужно обратно в числа — поможет цикл или `map`.
>   
>   
```python
   def expanded_form(num: int):
    # Сначала превращаем число в строку, теперь это текст
    num_str = str(num)
    # Теперь мы можем превратить строку в список отдельных символов
    print(list(num_str)) 

expanded_form(123) # Вывод в терминал: ['1', '2', '3']
```
