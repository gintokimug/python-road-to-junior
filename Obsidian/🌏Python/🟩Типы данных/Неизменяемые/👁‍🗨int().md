> - **Логика:** Напрямую из `int` в `list` попасть нельзя. 
>     
> - **Схема:** `int` ➡️ `str` ➡️ `list`.
> - Синтаксис:** `list(str(123))` даст тебе `['1', '2', '3']`. Помни: цифры внутри станут **строками**. Если нужно обратно в числа — поможет цикл или `map`.
>   
>```python
> def expanded_form(num: int):
 >   # Сначала превращаем число в строку, теперь это текст
>    num_str = str(num)
>  # Теперь мы можем превратить строку в список отдельных символов
>  print(list(num_str)) 
>
expanded_form(123) # Вывод в терминал: ['1', '2', '3']
>```
>
> Методы:
> - **round()**  - `round()`: округляет число до указанного количества знаков после запятой. По умолчанию эта функция округляет число до ближайшего целого и возвращает целое число без десятичных знаков:
>```python
my_int_1 = 4.798
>my_int_2 = 4.253
>
rounded_int_1 = round(my_int_1)
rounded_int_2 = round(my_int_2, 1)
>
print(rounded_int_1) # 5
print(rounded_int_2) # 4.3
>```
>- **abs()** - возвращает абсолютное значение числа.
>```python
num = -15
>
absolute_value = abs(num)
print(absolute_value) # 15
>```
 >- **pow()** -  возводит число в степень или выполняет возведение в степень по модулю.
>```python
result_1 = pow(2, 3)  # Equivalent to 2 ** 3
print(result_1)  # 8
>
result_2 = pow(2, 3, 5)  # (2 ** 3) % 5
print(result_2)  # 3
>```
