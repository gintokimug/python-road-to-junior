> [!abstract] Теория
> `None` — это специальный тип данных в Python (`NoneType`). Это не ноль `0`, не пустая строка `""` и не `False`. Это концепция **абсолютного отсутствия значения**. (Аналог `Null` в других языках). ## 1. Главное правило проверки (Синтаксис) Поскольку `None` в программе всегда существует в единственном экземпляре (это паттерн Singleton), его **нельзя проверять через двойное равно `==`**. Его проверяют через оператор `is`. 
> ❌ **Плохо:** `if user_id == None:`
>  ✅ **Профессионально:** `if user_id is None:` 
>  ✅ **Проверка на НЕ пустоту:** `if user_id is not None:`
> 
> None == False ( если задача булевая)
>
