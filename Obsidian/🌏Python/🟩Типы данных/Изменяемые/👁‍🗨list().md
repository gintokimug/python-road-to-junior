>[!abstract]
Еще один распространенный прием работы со списками — распаковка значений.
>
>Распаковка значений из списка — это метод, который используется для присвоения значений из списка новым переменным. Вот пример распаковки списка `developer` в новые переменные `name`, `age` и `job`.
>>[!Note]
>>```py
>>developer = ['Alice', 34, 'Rust Developer']
>>name, age, job = developer
>>
>>print(name) # 'Alice'
>>print(age) # 34
>>print(job) # 'Rust Developer'
>>```
>
>
>Если вам нужно собрать все оставшиеся элементы из списка, вы можете использовать оператор звездочки (`*`) следующим образом:
>> [!Note]
>>```python
>>developer = ['Alice', 34, 'Rust Developer']
>>name, *rest = developer
>>print(name) # 'Alice'
>>print(rest) # [34, 'Rust Developer']
>>```
>












# Преобразование типов (casting).

> [!abstract]
> - **Список ↔ Кортеж**:
>     
>     - `tuple([1, 2])` — делаем список неизменяемым.
>         
>     - `list((1, 2))` — превращаем кортеж в список, чтобы иметь возможность менять элементы.
>         
> - **Список ↔ Сет (Множество)**:
>     
>     - `set([1, 2, 2, 3])` — **быстрый способ удалить дубликаты** (останется `{1, 2, 3}`).
>         
>     - `list(my_set)` — превращаем сет обратно в список, чтобы работать с индексами (в сетах индексов нет).


# Slicing (Срезы)

> [!abstract]
> **Формула:** `объект[start : stop : step]`
> 
> - **start**: С какого индекса начинаем (включается). По умолчанию `0`.
>     
> - **stop**: Перед каким индексом останавливаемся (**НЕ включается**). По умолчанию — до конца.
>     
> - **step**: Шаг (через сколько прыгаем). По умолчанию `1`.
> 
> 
> - Инвертировать (развернуть),s[::-1]
> 
> - Взять последние 3 символа,s[-3:]
> 
> - Убрать первый символ,s[1:]
> 
> - Убрать последний символ,s[:-1]
> 
> - Только чётные элементы,s[::2]
> 
> - Копия всего списка,s[:]


# Встроенные функции:

> [!abstract] Теория
>  ❓len() - Возвращает количество элементов в объекте (длину списка, строки, словаря)
>  ❓sorted() - (списки, строки, кортежи, словари, множества) Создает **новый** список с отсортированными элементами. Оригинал остается нетронутым. Всегда возвращает list() 
>  ❓ min() and max()- есть необязательный аргумент  key=len, опционально под задачу
>  > [!пример]
> ```python
> words = ["apple", "pie", "banana"]
> print(max(words, key=len)) # Выведет: "banana" (самое длинное)
> ```


> [!abstract] Теория
> Методы списков:
> ❓.append() - Добавляет один объект как он есть ( если добавишь список в список, получишь вложенный список)
>- **Возвращаемое значение:** `append()` ВСЕГДА возвращает `None`.
 >   
>- **Типичная ошибка:** Попытка написать `result = my_list.append(x)`. В переменной `result` окажется пустота (`None`), а данные уйдут в `my_list`.
> >[!Пример]
> > ```python
> > my_list = [1, 2, 3]
> > result = my_list.append(4)
> > print(my_list) # [1, 2, 3, 4]  
> > print(result) # None
> > ```
> 
>>[!Пример] 
>>```python
>>a = [1, 2]
b = [3, 4]
a.append(b)
print(a)  # [1, 2, [3, 4]] — теперь это список внутри списка 
>>```
> 
> ❓.extend() - должен быть любой **итерируемый объект** (список, кортеж, строка, множество или словарь). Метод перебирает этот объект и добавляет каждый его элемент по отдельности. Как и `append()`, этот метод модифицирует существующий список и возвращает `None`.
> Если передать число (не итерируемое) — `TypeError`
**Правильно:** `my_list.extend(others)`
**Ошибка:** `new_list = my_list.extend(others)` (в `new_list` будет `None`)
>>[!Пример]
>>```Python
>>my_list = [1, 2]
>>my_list.extend([3, 4]) 
>>print(my_list)  # [1, 2, 3, 4] (а не [1, 2, [3, 4]])
>>```
>
>>[!Пример]
>>```python
>>names = ["Alice", "Bob"]
>>names.extend("Charlie")
>>print(names)  
>>Результат: ['Alice', 'Bob', 'C', 'h', 'a', 'r', 'l', 'i', 'e']
>>```
>
>❓.insert() -Метод вставляет элемент по указанному индексу. `insert` **раздвигает** список, а не заменяет старое значение.
>Синтаксис: `list.insert(index, object)`
> Особенности:
>
>- **Сдвиг элементов:** В отличие от `append()`, этот метод заставляет Python "двигать" все элементы справа от места вставки. Если список огромный, вставка в начало будет медленной ($O(n)$).
  >  
>-  **Индексы "на вырост":** Если указать индекс, превышающий длину списка, ошибки не будет — Python просто добавит элемент в самый конец.
>>[!Пример]
>>```python
>>nums = [1, 2, 3]
>>nums.insert(1, 99) 
>>Ожидание: [1, 99, 3]
>>Реальность: [1, 99, 2, 3]
>>```
>
>>[!Пример]
>>```Python
>>colors = ["red", "blue"]
>>colors.insert("green", 0) # TypeError: 'str' object cannot be interpreted as an integer
>>```
>
>❓ remove() -Метод удаляет **первое встретившееся** значение из списка. Синтаксис: `list.remove(value)` слево направо, первое попадание выход -если не находит элемент,ValueError
> Особенности:
>
>- **Поиск по значению:** Он ищет сам объект, а не его индекс.
>
>- **Удаляет только одного:** Если в списке три "пятерки", `remove(5)` удалит только первую.
>>[!Пример]
>>```Python
>>users = ["Alice", "Bob"]
>>users.remove("Charlie") # ValueError: list.remove(x): x not in list
>>```
>
>❓ clean() - Полностью удаляет все элементы из списка `list`, словаря `dict` или множества `set
>Особенности:
>
>- **Синтаксис:** `list.clear()`. Аргументов не принимает.
  >  
>- **In-place:** Изменяет исходный объект.
>>[!Пример]
>>```Python
>>results = []
temp_data = [1, 2, 3]
results.append(temp_data)
>>temp_data.clear() 
>>print(results) # Результат: [[]] — данные пропали и из основного списка!
>>```
>
>❓ index() Ищет элемент в списке и возвращает его **индекс** (позицию). Синтаксис: `list.index(value, start, end)`.
> Особенности:
>
>- **Первое вхождение:** Как и `remove()`, находит только первый попавшийся элемент слева.
  >  
> - **Ограничение области:** Можно указать, в каком диапазоне искать (`start` и `end`).
>
>>[!Пример]
>>chars = ["a", "b", "c"]
>>print(chars.index("z")) # ValueError: 'z' is not in list
>
>>[!Пример]
	>>nums = [10, 20, 30, 40]
>>print(nums.index(10, 2, 4)) # ValueError: 10 is not in list (потому что ищем с 2-го индекса)
> 
> ❓pop() Удаляет элемент по индексу и **возвращает** его. Это единственный метод удаления, который >"отдает" тебе значение.
>
>Особенности:
>
>- **По умолчанию:** Если не указать индекс, удаляет и возвращает **последний** элемент (`-1`).
  >  
>-  **Стек:** Благодаря `pop()` и `append()`, обычный список легко превращается в структуру данных "Стек" (LIFO — последний пришел, первый ушел).
>>[!Пример]
>>```python
>>tasks = ["завтрак", "работа", "сон"]
>>current_task = tasks.pop(0) # Взяли первую задачу
>>print(f"Сейчас я делаю: {current_task}")
>>```
>
>❓ count() - Считает, сколько раз конкретное значение встречается в списке.
>Особенности:
>- **Синтаксис:** `list.count(value)`.
  >  
> -**Точное совпадение:** Считает только те элементы, которые полностью идентичны искомому.
>
>❓ sort() - меняет список на месте(при следующем вызове норм),меняет оригинал, возвращает None (нельзя положить в переменную, там пусто)
> 2 правила при работе с сортировкой :
> 1.  Если оригинал НЕ нужен (используем `.sort()`)
>	Мы просто вызываем метод, а на следующей строке работаем с тем же списком.
>    ```python
>nums = [3, 1, 2]
nums.sort()  # Сортируем "на месте"
>
>print(nums)  # [1, 2, 3] — теперь список изменен навсегда
>    ```
>    
>    2.  Если оригинал НУЖЕН (используем функцию sorted())
>	Это самый безопасный способ. Функция `sorted()` берет список, делает его копию, сортирует её и **возвращает** как результат. Оригинал остается нетронутым.
>```python
>nums = [3, 1, 2]
new_nums = sorted(nums) # Вот здесь в переменную попадет новый список
>
>print(nums)     # [3, 1, 2] — старый список в порядке
>print(new_nums)  # [1, 2, 3] — а это отсортированная копия
>```
>
>❌Пример вызова с ошибкой 
>```python
>nums = [3, 1, 2]
>sorted_nums = nums.sort() 
>print(sorted_nums) # None
>```
>

> [!warning] Внимание
>(in-place)
>Это когда метод физически изменяет оригинальный объект (например, список) в памяти, не создавая его копию.
>Список из миллиона пользователей, весом 1ГБ , чтобы отсортировать создавался бы новый список 1ГБ, а так он меняет уже имеющийся(важно не забывать, что данные будут уничтожены)
>Изменяя список *на месте*, мы тратим **0 лишних байт**. Возвращая `None`
>**Какие методы работают In-place (и возвращают `None`):** 
>- Списки (`list`): `.append()`, `.extend()`, `.insert()`, `.remove()`, `.clear()`, `.reverse()`, .sort(). 
>- Словари (`dict`): `.update()`, `.clear()`.
>- Множества (`set`): `.add()`, `.remove()`, `.discard()`, `.clear()`
>
 >>❌
> >```python
> >python my_list = [3, 1, 2] 
> >my_list = my_list.sort() # Питон отсортировал оригинал, а вернул None 
> >print(my_list) # Выведет: None. Мы навсегда потеряли наши данные! 
> >```
>
>>✔
>>```python
>>my_list =[3, 1, 2]
>>my_list.sort() # Просто вызываем метод
>>print(my_list) # Выведет: [1, 2, 3]
>>```
>
>Если всё таки нужна изменённая копия,а оригинал надо сохранить лучше использовать встроенные функции sorted(my_list)


# Генератор списков(list compehension)

Генератор списка состоит из двух частей: выражения, которое определяет преобразование каждого элемента, и источника данных с циклом for для итерации. Общий синтаксис:

> [!NOTE]
> [выражение for элемент in источник].
> [выражение for элемент in источник if условие]
