>[!abstract] Теория
 break и continue — это **руль и тормоза для циклов**. Они управляют бизнес-логикой программы.
>
>- **break** — это красная кнопка "СТОП". Конвейер полностью останавливается.
  >  
>- **continue** — это кнопка "БРАК". Конвейер сбрасывает текущую деталь в мусорку и сразу берет следующую, не останавливая всю ленту.
>
Эти операторы работают **ТОЛЬКО внутри циклов** (`for` и `while`). Они нужны для того, чтобы не делать лишнюю работу, тем самым оптимизируя скорость программы (снижая O(n)).
>
>🛑 **Оператор `break` (Аварийный выход)**
>
>**Пример:** Если в цикле от 1 до 10 сработает `break` на цифре 5, то цикл завершится. Цифры 6, 7, 8 и дальше даже не будут рассматриваться
>
>>[!Note] Пример
>>```python users = ["Анна", "Иван", "Сергей", "Петр", "Мария"] 
>>for user in users: 
>>print(f"Проверяем: {user}") 
>>if user == "Сергей":
>>print("Нашли! Останавливаем поиск.")
>>  break # Выбивает нас из цикла навсегда 
>>  # Вывод: # Проверяем: Анна 
>># Проверяем: Иван 
>>  # Проверяем: Сергей 
>>  # Нашли! Останавливаем поиск. 
>>  # (До Петра и Марии дело даже не дошло)
>
 >
 >⏭️ **Оператор `continue` (Пропуск шага)**
>
**Суть:** Прерывает только **текущую итерацию** (шаг) и сразу перекидывает программу на начало цикла (к следующему элементу).
>
**Где используется (Пример):**  
Фильтрация. Допустим, мы считаем общую сумму зарплат, но нам нужно проигнорировать уволенных сотрудников (у которых зарплата равна 0 или None).
>**Пример:** Если в цикле от 1 до 5 сработает `continue` на цифре 3, то тройка будет пропущена, но цикл продолжит работу и перейдет к цифре 4.
>
>> [!Note] Пример 
>>```python
>>salaries = [100, 0, 150, None, 200]
>>total = 0
>>
>>for s in salaries:
>>     Если зарплаты нет, пропускаем этого человека
>>    if s is None or s == 0:
>>        continue  # Прыгаем обратно в начало цикла (к следующему 's')
>>   
>>    Код ниже не выполнится для 0 и None
>>    total += s
>>    print(f"Добавили {s}. Итого: {total}")
>>
